# AI Resume Chat

An AI-powered Resume Chat application built from scratch to learn Retrieval-Augmented Generation (RAG) concepts and modern AI application architecture.

## Project Goals

This project is being built step-by-step to understand:

* PDF ingestion
* Text extraction
* Chunking
* Embeddings
* Semantic Search
* Vector Databases
* Retrieval-Augmented Generation (RAG)
* AI Application Architecture

## Current Features

* Upload PDF Resume
* Extract Text from PDF
* Store Uploaded Files
* Basic Document Processing Pipeline

## Tech Stack

* Next.js 16
* TypeScript
* PDF Processing
* Git & GitHub
